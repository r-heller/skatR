# skatR: Analysis and Simulation of the Card Game Skat

A toolkit for the German card game Skat. Provides a configurable rules
engine supporting both official tournament rules and common casual
variants, bidding value computation, players ranging from rule-based
heuristics through determinized Monte Carlo search to an exact
double-dummy solver, Monte Carlo simulation over many deals, and tidy
analysis and visualisation of outcomes. Card play, scoring and
game-value calculation follow the standard 32-card Skat deck.
